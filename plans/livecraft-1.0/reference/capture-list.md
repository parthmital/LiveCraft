Purpose: canonical list of Live 12.4 UI reference states (`1920x1080`, `100%` zoom, `dark` and `light` themes), their LiveCraft-authored `.als` fixtures, capture steps, and pixel comparison regions for `tools/ui_diff.py` and `tools/ui_measure.py`.
Read when: capturing Live 12.4 reference PNGs (M12+), implementing `crates/livecraft-ui/src/capture_states.rs`, running `tools/ui_diff.py`, or verifying UI milestones (M13 to M41).
Last verified: 2026-11-10.

## Capture Protocol Summary

- Window and scale: `1920x1080` client area, `100%` OS display scaling, Live Settings > Display & Input Zoom `100%` (see `plans/livecraft-1.0/reference/UI-FIDELITY.md`).
- Themes: each state is captured in `dark` (Live 12.4 default) and `light` (manual-screenshot light theme).
- Storage: reference PNGs and sidecar JSONs are saved only under Git-ignored `.agent-local/reference/live/<state-id>.png` and `<state-id>.json`, never committed.
- Clean-room fixtures: every `.als` fixture under `fixtures/ui/` is authored by LiveCraft (`AlsDocument::from_project`) and never copied from Ableton files.
- State count: 30 `batch-1` rows (15 states x 2 themes) and 292 `batch-2+` rows (146 additional states x 2 themes), for 322 total rows (161 distinct UI states).
