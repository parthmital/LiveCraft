# Decisions

Purpose: every plan-wide decision with its reason, so no task re-decides it. Read when: a task or milestone needs a choice not stated in its own file.
Last verified: 2026-10-28.

Library evidence and alternatives are in the root `RESEARCH.md`. Architecture decisions are in `TARGET-ARCHITECTURE.md`. A decision changes only through a new entry here that marks the old one Superseded.

## Product

| ID  | Decision                                                                                                                                                                                                          | Reason                                                                                                                                                                                                                                       |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D01 | Parity target is Live 12.4 Suite, as documented by the local manual and the installed 12.4.                                                                                                                       | Latest stable line (12.4.7, 2026-10-22); the manual and install match it.                                                                                                                                                                    |
| D02 | Product name stays LiveCraft. No Ableton logo, name, or trade dress in branding; "compatible with Ableton Live" only in descriptions.                                                                             | Trademark law; the Storytold Craft apps follow the same rule.                                                                                                                                                                                |
| D03 | UI layout, terms, and behaviour follow Live exactly; visual assets (icons, fonts) are original or openly licensed.                                                                                                | Fidelity goal within clean-room limits.                                                                                                                                                                                                      |
| D04 | Max for Live itself is not reproduced. Its bundled devices (chapter 33) are rebuilt natively; programmability comes from the scripting and control server in M42.                                                 | Max is proprietary (Cycling '74).                                                                                                                                                                                                            |
| D05 | Splice integration, Ableton account features, Packs store, and Push firmware are out of scope.                                                                                                                    | Proprietary services.                                                                                                                                                                                                                        |
| D06 | Core Library content is not shipped. LiveCraft ships its own small CC0 or self-made factory content. Indexing clause superseded by D30.                                                                           | Ableton content is licensed only to Live users.                                                                                                                                                                                              |
| D07 | Platforms: Windows 10 and 11 (x64, primary), macOS 13+ (universal), Linux x64 (Live has no Linux build).                                                                                                          | Reach beyond Live.                                                                                                                                                                                                                           |
| D30 | Standalone: LiveCraft needs no Ableton software, account, or content, and never reads the Core Library or Packs installed by Live. Live file formats the user opens (.als, .alc, .adg, .adv, .alp) stay in scope. | Owner decision, 2026-10-28. Supersedes the indexing clause of D06 and answers D-OWN-6 with no.                                                                                                                                               |
| D31 | Licence: the whole repository is GPL-3.0-or-later, replacing MIT OR Apache-2.0. Release builds enable `link` (Ableton Link), `asio` (ASIO SDK), and `stems` (model download after consent).                       | Owner decision, 2026-10-28. Link is GPL-2.0-or-later and the ASIO SDK is GPLv3, so distributed binaries must be GPL. The project is free and open, with no monetisation. Supersedes the licence clause of D13 and the release clause of D14. |

## Engineering

| ID  | Decision                                                                                                                                                                                                                            | Reason                                                                                                                                           |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |

Superseded in part by D31: release builds enable both features.                                                           |
