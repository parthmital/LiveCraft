# Decisions

Purpose: every plan-wide decision with its reason, so no task re-decides it. Read when: a task or expansion needs a choice not stated in its own file.
Last verified: 2026-10-27.

Library evidence and alternatives are in the root `RESEARCH.md`. Architecture decisions are in `TARGET-ARCHITECTURE.md`. A decision changes only through a new entry here that marks the old one Superseded.

## Product

| ID  | Decision                                                                                                                                                                 | Reason                                                                    |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| D01 | Parity target is Live 12.4 Suite, as documented by the local manual and the installed 12.4.                                                                              | Latest stable line (12.4.7, 2026-10-22); the manual and install match it. |
| D02 | Product name stays LiveCraft. No Ableton logo, name, or trade dress in branding; "compatible with Ableton Live" only in descriptions.                                    | Trademark law; the Storytold Craft apps follow the same rule.             |
| D03 | UI layout, terms, and behaviour follow Live exactly; visual assets (icons, fonts) are original or openly licensed.                                                       | Fidelity goal within clean-room limits.                                   |
| D04 | Max for Live itself is not reproduced. Its bundled devices (chapter 33) are rebuilt natively; programmability comes from the scripting and control server in M42.        | Max is proprietary (Cycling '74).                                         |
| D05 | Splice integration, Ableton account features, Packs store, and Push firmware are out of scope.                                                                           | Proprietary services.                                                     |
| D06 | Core Library content is not shipped. LiveCraft ships its own small CC0 or self-made factory content and indexes the user's existing Live library read-only when present. | Ableton content is licensed only to Live users.                           |
| D07 | Platforms: Windows 10 and 11 (x64, primary), macOS 13+ (universal), Linux x64 (Live has no Linux build).                                                                 | Reach beyond Live.                                                        |

## Engineering

| ID  | Decision                                                                                                                                                                                                                            | Reason                                                                                                                                           |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| D10 | Rust 1.99.1 pinned; edition 2024 after Task P0-08; MSRV declared as 1.95 (egui_kittest needs it).                                                                                                                                   | Reproducible builds; latest edition.                                                                                                             |
| D11 | One-command launcher is `cargo dev` (a Cargo alias for `run --bin livecraft --`), and `cargo xtask ci` is the one-command check. No Node.js.                                                                                        | The repository is pure Rust; adding Node for a launcher adds a runtime for nothing.                                                              |
| D12 | egui and eframe 0.37 with the wgpu renderer; on Windows the backend is DX12 unless `WGPU_BACKEND` is set.                                                                                                                           | Vulkan crashed on the reference machine on 2026-10-27 (segmentation fault after loader warnings); DX12 and GL worked.                            |
| D13 | Dependencies are added only with exact versions named in a task; `cargo-deny` allows MIT, Apache-2.0, BSD, ISC, Zlib, Unicode, CC0, BSL-1.0, MPL-2.0, OFL-1.1 and denies GPL family by default.                                     | Keeps the MIT OR Apache-2.0 licence of the product.                                                                                              |
| D14 | GPL-licensed components (Ableton Link via `rusty_link`, Steinberg ASIO SDK via cpal `asio`) live behind opt-in Cargo features `link` and `asio`, off by default and off in CI release builds until D-OWN-1 and D-OWN-2 are decided. | Licence compatibility.                                                                                                                           |
| D15 | quick-xml moves to 0.42.0 in Phase 0 (Task P0-11) with a scripted adaptation of the current parser; M09 still replaces the parser with the lossless one.                                                                            | 0.36.2 has RUSTSEC-2026-0194 and RUSTSEC-2026-0195 on untrusted input (found by cargo-deny on 2026-10-27).                                       |
| D29 | eframe's `accesskit` feature stays off until M40.                                                                                                                                                                                   | On 2026-10-27 it pulled in unmaintained `zvariant`, `zbus_names`, `zvariant_derive` (RUSTSEC-2026-0370 to 0372) through the Linux AT-SPI bridge. |
| D16 | Real-time crates: `rtrb` 0.4.1, `basedrop` 0.1.3, `triple_buffer` 9.0.0, `assert_no_alloc` 1.1.2 (dev and debug).                                                                                                                   | See RESEARCH.md#real-time-concurrency-2026-10-27.                                                                                                |
| D17 | Media crates: `symphonia` 0.6.1, `rubato` 5.0.1, `signalsmith-stretch` 0.1.3, `realfft` 3.5.1, `hound` 3.5.1.                                                                                                                       | See RESEARCH.md#audio-files-resampling-time-stretch-2026-10-27.                                                                                  |
| D18 | Plug-ins: `clack-host` 0.2.0 (CLAP) and `vst3` 0.3.0 (VST3) in an out-of-process host; AU via a macOS-only module; no VST2.                                                                                                         | Safe hosting; VST2 SDK no longer licensable.                                                                                                     |
| D19 | MIDI I/O: `midir` 0.11.1.                                                                                                                                                                                                           | Only maintained cross-platform option.                                                                                                           |
| D20 | Testing crates: `proptest` 1.12.0, `insta` 1.49.0 (text snapshots), `egui_kittest` 0.37.0 with `wgpu` and `snapshot` features, `criterion` 0.8.2 for benchmarks.                                                                    | Current stable versions on 2026-10-27.                                                                                                           |
| D21 | Error types: `thiserror` 2 in library crates, `anyhow` only in binaries, xtask, and tests.                                                                                                                                          | Typed errors at boundaries.                                                                                                                      |
| D22 | Logging: `log` facade in libraries, `env_logger` in the binary; never log on the audio thread.                                                                                                                                      | Already in use; simple.                                                                                                                          |
| D23 | Browser index store: SQLite through `rusqlite` 0.41.0 with the `bundled` feature.                                                                                                                                                   | Fast tag and text queries; public-domain engine.                                                                                                 |
| D24 | Scripting: `rhai` 1.27.0 (MIT OR Apache-2.0) for MIDI tools and control scripts in M42; audio-rate user DSP only through CLAP plug-ins.                                                                                             | Pure Rust, sandboxed; audio-rate scripting is unsafe for real time.                                                                              |
| D26 | Control server: JSON-RPC 2.0 over stdio and localhost TCP written on `serde_json` without an async runtime; MCP through `rmcp` 3.8.0 in a separate optional binary mode.                                                            | The registry is synchronous; an async runtime in the app core adds risk for no gain.                                                             |
| D27 | Test temp files: `tempfile` 3.27.0 (dev-dependency). Hashes for downloads and golden files: `sha2` 0.11.1.                                                                                                                          | Current versions on 2026-10-27.                                                                                                                  |
| D28 | Version rule for later milestones: a milestone expansion may move a pinned version forward to the latest release that is at least 14 days old, recording the change here as a new row.                                              | Long plan; versions age.                                                                                                                         |
| D25 | Note naming: MIDI 60 is C3 in every UI, CLI help, and file.                                                                                                                                                                         | Live's convention (manual chapter 10).                                                                                                           |
